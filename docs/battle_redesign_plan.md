# 战斗重构框架（待实施）

先完成纯 HTML 表情编辑器，再按下列阶段推进战斗。本文件是设计和验收约定，不代表功能已完成。

## 单一更新流程

每帧依次运行：命令优先级 → 目标保持/选择 → 机型战术决策 → 航线与推进 → 武器瞄准/射界 → 开火与弹道 → 命中/伤害。每项状态只有一个负责写入的模块。

锁定对象不代表机头必须持续盯着它。战术模块给飞行模块航点/目标速度，飞行模块独占机头朝向和速度更新。武器根据实际机头、炮口与武器射界判断是否允许发射；不能为了开火直接改机体朝向。未来可增加独立炮塔朝向，仍不能修改推进方向。

手动移动、返航、维修等命令优先于自动攻击航线。目标无效后清理该目标的机动状态；有效目标不因每次受击或帧更新反复切换。

## 实施顺序与验收

| 阶段 | 工作 | 验收 |
|---|---|---|
| 1 | 开火诊断和基础参数表 | 可统计冷却、热量、射程、射界、能量、目标无效造成的漏射；区分配置间隔与实际间隔 |
| 2 | 推進/机头统一、单一运动写入者 | 直飞、掉头、刹车、绕障碍均稳定；帧率变化不明显改变路径；尾喷与前进方向一致 |
| 3 | 狙击机完整攻击航线 | 接敌→短瞄准→射击→脱离→转弯准备下发；双方交战不无限漂移，不因冷却空转长期不开枪 |
| 4 | 通用索敌与机型战术 | 同目标保持稳定；拦截机掠袭、多用途进攻、重机压制、炮击远攻、维修支援分别验证 |
| 5 | 普通攻击/必杀技统一平衡 | 按有效血量、命中率、实测间隔、范围收益比较；单挑与混编测试双方对称 |
| 6 | 特效与迁移清理 | 炮口、射界、尾喷、弹道吻合；通过回归后删除旧入口，保留对外 Unit 接口 |

## 狙击和平衡基准

当前狙击基础冷却 6.2 秒，再乘全局 1.6，实际至少约 9.92 秒；窄射界可能进一步增加间隔。血量乘 5、伤害乘 0.55，导致技能与普通攻击都明显偏弱。先测再调，不能简单对全部单位增加同一倍率。

初始设计目标：对同级普通战机、无护盾无强化，一发普通狙击命中约造成三分之一血量；重装与母舰不采用固定百分比扣血。必杀技收益明显高于普通单发，同时把贯穿和多目标伤害计入平衡。具体伤害和冷却在攻击航线稳定后确定。

每阶段执行 `python tools/check_lua.py`，补充该阶段行为测试。目录整理跟随已验证的功能迁移；暂不继续拆 main.lua，不改队伍、皮肤和对白目录。
