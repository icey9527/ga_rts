# 关卡与对白编写指南

## 从一个关卡开始

同一关由两份文件构成：`levels/level_07.tbl` 放地形和背景，`levels/scripts/level_07.lua` 放任务和固定剧情。编号一致，运行时自动匹配。

普通剧情人物在右上通讯区显示；可可使用左下专用位置，诺阿使用右下专用位置，并带立绘。右侧后勤打开时，通讯区域自动左移。不要在关卡文件内写固定像素坐标。

```lua
return {
    objective={type="escort",label="护送资料舰通过小行星门",destination={2400,550}},
    reinforcements={
        {time=35,team=1,unit="light",count=2,offset={2000,-650}},
    },
    intro={
        {id=25,text="卡兹亚君，先检查护航队形。"},
        {id=22,text="资料舰的航线已经录入。请保护它抵达集结区。"},
    },
    interludes={
        {time=35,id=22,text="上方出现敌方增援，先挡住入口。",kind="hit"},
        {when={type="escort_progress",value=0.7},lines={
            {id=25,text="最后一段航路。卡兹亚君，别急着追击。"},
            {id=0,text="明白。护航队保持位置。"},
        }},
    },
    victory={{id=25,text="护送完成，做得好。",kind="praise"}},
    defeat={{id=22,text="护送目标失能。任务优先级需要重新考虑。",kind="failed"}},
}
```

开场剧情暂停战斗。回车或单击继续，空格/Esc 或右键跳过。中场剧情随战斗时间触发，不暂停指挥。胜败剧情在结果页继续播放。跳过开场不会跳过未来中场事件。

## 一句对白的字段

| 字段 | 意义 |
| --- | --- |
| `id` | 角色数字 ID，例如 0 卡兹亚、6 枣、22 诺阿、25 可可 |
| `text` | 实际显示的中文台词 |
| `kind` | 表情类别：`idle`, `attack`, `hit`, `praise`, `failed`, `skill` |
| `duration` | 可选，显示秒数；默认按字数计算，至少 5.5 秒 |
| `slot` | 可选：`radio`, `coco`, `noah`；通常让角色 ID 决定默认位置 |

无需写角色显示名、头像路径或立绘路径。演员先从当前战场按 ID 查找；若不在战场，则创建通讯演员，适用于可可、诺阿及远端指挥部。

关卡脚本是静态数据，不要给对白表写入 `unit`、`game`、已播放状态等运行时引用。Lua 的 `require` 会缓存返回值，把这些数据放进去会污染第二次开局。

## 中场触发条件

| 写法 | 触发时机 |
| --- | --- |
| `time=35` | 战斗时间到 35 秒；暂停和慢动作会影响战斗时间 |
| `when={type="losses",count=2}` | 我方累计两个单位失能 |
| `when={type="enemy_remaining",count=3}` | 当前存活敌舰不超过三个 |
| `when={type="escort_progress",value=0.7}` | 护送进度达到 70% |
| `when={type="flag",flag="research"}` | 实际研究指令已成功入队 |

同一事件每关只触发一次。事件可以自身包含 `id/text`，也可以用 `lines` 给出多句连续对话。多个事件同帧触发时按脚本顺序排队。请将状态描述写得准确，例如没有护盾周期逻辑时，不要说“护盾窗口已经打开”。

可用教学标志包括 `pan`, `zoom`, `move`, `attack`, `follow`, `skill`, `economy`, `collect`, `recruit`, `research`。新增标志应在成功操作后设置，不要在用户只是点了按钮但操作失败时设置。

## 任务目标

| `type` | 完成条件 | 额外字段 |
| --- | --- | --- |
| `eliminate` | 清空当前敌舰，并且没有等待中的敌方波次 | 无 |
| `flagship` | 敌方母舰失能 | 无 |
| `survive` | 我方母舰存活至指定时长 | `duration` |
| `escort` | 自动护送舰抵达集结区，半径 110 | `destination={dx,dy}` |

所有普通演习任务都要求我方母舰存活。护送舰失能额外判负。即使目标已完成，母舰同帧失能也不判胜。

护送坐标和脚本增援 `offset` 以当前我方母舰初始位置为原点，单位是已经缩放后的世界距离。TBL 中旧波次坐标则由关卡加载器按地图比例缩放，二者不要重复乘比例。

任务护送舰航速为 28，独立于玩家战机。当前三关无人干预样本约 62 至 78 秒完成；敌方轻快机、拦截机和狙击机会在接近时优先攻击护送目标。增加护送航线长度时，同时检查敌人是否有机会接触目标。

脚本 `reinforcements` 支持 `time`, `team`, `unit`, `count`, `offset`, `id`。`team=0` 是玩家所选舰队，`team=1` 是对手；不随剧情人物的所属队伍自动推断。`id` 仅指定这一波第一台机体的驾驶员，其余使用机型角色池。

## 角色对白怎么扩写

在 `teams/<队伍>/chara/004/dialogue.lua` 的 `friendly` 下添加我方事件，在 `enemy` 下添加少量演习对手台词。不要在这里添加固定开场或胜败剧情。

```lua
return {
    friendly={
        command={"指令确认。保持队形，准备行动。"},
        ready={"特殊装备就绪，等待释放指令。"},
        follow={"队形稳定，继续保持间距。"},
        follow_reply={"跟紧即可，遇到火力及时转向。"},
        interaction={"卡兹亚，频繁改令会打乱队形。请先确认目标。"},
    },
    enemy={
        attack={"检查你们的侧翼，我们开始了。"},
        hit={"这一击有效。重新调整队形。"},
        praise={"这里的空隙，下一次记得补上。"},
        lost={"判定失能。本轮由你们获胜。"},
    },
}
```

敌方不会播报接令、我方指令失败和技能就绪。其红色边框由阵营自动决定。每类事件的台词数组会轮换，扩写时直接添加句子即可。

双人互动如果启用，应放在对应队伍的角色对白文件中；镜头跟随使用 `camera_follow_*`，机体跟随命令使用 `formation_follow_*`。不要再创建或引用旧的 `dialogue/exchanges.lua`。

## 人物规则

- 卡兹亚是玩家身份，现代自然口语；只有他称莉莉为“莉莉姐”。
- 阿普莉可特保留“先生”，语气柔和克制。
- 娜诺娜诺不用“我”，用“娜诺娜诺”或省略主语。
- 卡露娅和塔琪拉区分人格；对咪莫莱特不用敬语。
- 枣自称“我”，对敌人可用“尔”，不要强行古化。
- 可可称呼他人保留“君”；诺阿冷静高傲，技术判断清楚，但不要每句话都辱骂玩家。
- 0 至 7 中莉莉是中尉，其余按少尉；10 至 15 中佛特是中校，其余少校。
- 塔克特为司令、雷斯特为副官；阿尔茉元气，对雷斯特有单恋互动。
- 医生不要译成老师；克罗瓦偏东北口语；克萝奈朴实北方口语，称卡兹亚为“卡兹漾”。

## 作者验收

检查该关两队都能开局、开场可跳过、剧情不出现在屏幕中央、中场条件只触发一次、胜败两套台词都存在。涉及波次时必须确认它真的生成。涉及护送时必须实际推进到目的地，并测试护送舰被击毁。

请避免把“资料舰到达”“护盾解除”“支援已抵达”等确定事实写在纯时间触发里，除非玩法也保证同一时刻发生。新的复杂剧情先写最小示例并加触发测试，再铺长文本。
