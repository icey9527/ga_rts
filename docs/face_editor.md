# 表情工作室（纯 HTML）

用桌面版 Chrome 或 Edge 打开 `tools/face_editor.html`。这是单文件应用，双击或拖入浏览器即可，不需要 Python、Node 服务、安装依赖或访问 localhost。

1. 点击“选择游戏目录”，选择 `rts_game` 或其中的 `teams` 文件夹，允许浏览器编辑文件。
2. 选择队伍、原皮/皮肤和角色。皮肤中有 face 图片而没有 chara.tbl 时，也可以编辑。
3. 将候选图片拖进普通、攻击、日常或受击槽位；也可以先点候选，再点槽位。
4. 看到“已自动保存”后修改已经写入本地配置，不需要保存按钮。

图片完整显示、不裁切，支持文件名搜索和已使用槽位标记。清除指定会移除该字段；皮肤可能继承原皮的显式配置，否则游戏自动按文件名选择。保存期间锁住操作，防止角色切换串写。其他窗口改过配置时拒绝覆盖，点击重新载入再操作。

只改当前角色/皮肤 `chara.tbl` 的 `[chara]` 中四个表情字段，保留其他配置段和 UTF-8 BOM、换行风格。使用浏览器可写文件流，关闭流后才更新成功状态；不修改图片或游戏存档。游戏有图片缓存，重启游戏后查看。

浏览器的目录授权是直接保存本地文件的必要步骤。目录句柄保存在浏览器 IndexedDB；重新打开时权限仍有效就自动连接，否则点击“连接上次目录”重新授权，无需再找文件夹。清理浏览器数据或禁用存储后需要重新选择。若没有文件选择 API，页面明确提示使用 Chrome/Edge；内嵌浏览器不保证支持。

槽位头像为 96px 正方形，候选头像为 72px 正方形，完整显示不裁切；隐藏图片文件名，搜索和鼠标悬停仍可定位文件。

所有 CSS、交互和文件读写均内嵌在 HTML 中，无远程依赖或上传。开发回归可选运行 `node tools/test_face_editor.cjs`，测试临时目录中的原皮隔离、皮肤配置创建、保存重读、配置段保留、外部修改冲突和清除指定；使用编辑器本身不需要 Node。
