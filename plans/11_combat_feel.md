# 计划 11：战斗手感——技能武器绑定、后摇与补给滑行

来源：用户反馈 2026-09-11（"必杀技最好和武器绑定""狙击放完技能马上离开很假""补给之后的滑行问题"）。

## 阶段 A：必杀技与武器绑定

- `skill_data.weapon = "<weapon_id>"`（如狙击 `"sniper_rifle"`）：必杀是该武器的
  "超级射击"，而不是独立系统。
- `can_execute` 增加判定：绑定武器存在且未过热。
- `execute` 后该武器进入冷却（冷却 = 技能强度的一部分，防"普攻+必杀双轨无代价"）。
- 演出与面板读取该武器的射程/弹速/视觉（贯穿光束的起点 = 该武器炮口）。
- 未声明绑定的技能维持现状（母舰修复类不依赖武器）。

## 阶段 B：技能后摇（recovery）

- `skill_data.recovery`，按技能族给默认值（charge_beam 约 1.2 秒、dash 0.5、
  轰炸 0.8；配置可覆盖）。
- 后摇窗口内：机型战术的换位/脱离暂停（狙击放完贯穿**站在原地**、只允许
  机头追踪目标），后摇结束才恢复机动；受击不打断（重甲的代价换来的输出窗口）。
- 实现：`battle/skills/registry.lua` 的 execute 写入 `unit.skill_recovery`，
  各机型战术引擎在 fly 头部检查（与 dash 互斥的同类机制）。
- 演出提示：后摇期间机身微光/姿态变化（观感，不参与结算）。

## 阶段 C：补给离港滑行

- 现状：`_state_supplying` 补满后按单位 ID 角度选离港点
  （母舰半径+机体半径+150），机体带惯性滑行——观感待调。
- 排查并调整：离港点距离、到达判定半径、离港段限速（有推船离港的
  加速感，但 1-2 秒内稳定进入巡航，不漂远、不折返）。
- 用回归锁行为：离港后 N 秒内距母舰距离单调增加且超 400。

## 验收

- [ ] 狙击放完贯穿原地滞留 ≥ recovery 秒（回归断言），期间机头可追踪。
- [ ] 绑定武器的技能释放后该武器冷却同步（断言）。
- [ ] 离港滑行回归通过；全量 verify 绿。
