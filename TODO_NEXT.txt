深空指挥：后续接手清单
========================

这份清单同时记录已经完成的基线和仍未完成的工作。接手者先阅读本文件与 MAINTENANCE.md，再按优先级开发。

一、已经完成
------------
- 伪 3D RTT 镜头：中键平移、边缘滚屏、滚轮缩放、敌方观察跟随。
- 所有存活舰船常驻小头像；定位箭头位于头像下方；敌方使用红边。
- 补给流程会返航、补给、离舰，并清理旧攻击/跟随目标。
- 角色身份、驾驶员名字、机体类型和必杀立绘已经分离映射。
- 已有蓄力贯穿光束、轰炸扫射、突进撞击、护盾、全图维修、工具维修。
- 关卡已支持开场、中场、胜利、失败剧情，以及护送、限时、生存、母舰目标。
- 对白已拆为关卡剧情、判定对白、随机闲聊和双人互动。
- 已有采集、研究、生产、招募、矿脉、偏好保存和基础音效。
- 音效运行目录已迁移到 assets/se，OGG 验证通过。
- 通讯独立槽位与队列完成：可可/诺阿/雷斯特/阿尔茉/索尔贝各持 FIFO 队列，
  诺阿教学时可可面板完全让位，后勤教学不再重复显示；可可取消开场自我介绍。
- 塔克特队分工完成：雷斯特正式指导与批评，阿尔茉元气鼓励，塔克特只在剧情与闲聊；
  新增雷斯特与塔克特损友互动、雷斯特与阿尔茉队伍教学。
- 敌方后勤索尔贝(074)完成：红色气泡、红边头像、专属台词、战损阈值反应；
  敌我后勤均参与欢呼、批评与战况播报。
- 敌方必杀完成：更小的红色特写、独立扫描线特效、慢动作与我方一致；
  必杀区域与通讯列统一随舰队管理面板左移。
- 右下母舰状态已显示卡兹亚头像；诺阿立绘已裁上半身与可可对齐。
- 剧情一次性回归断言完成：interlude 单次触发、finish 幂等、跳过开场不阻断中场。
- 背景素材瘦身完成：assets/backgrounds 从 205MB 减到 9MB，
  156 个未引用文件归档至 dump/raw/backgrounds（含 MANIFEST.txt）。
- 根目录验证临时输出已清理，.gitignore 已就位（忽略 dump 与验证输出）。
- 战队顾问替换完成：选塔克特队时雷斯特接战术位（可可位）、阿尔茉接后勤位（诺阿位），
  可可/诺阿转入侧翼频道；经济与提醒台词按角色性格双套成文（config/economy_lines.lua）。
- 地图内角色唯一完成：随机增援、生产、招募不再重复选已上场驾驶员。
- 主菜单/战斗 ESC 防误触完成：菜单退出需确认弹窗，战斗中 ESC 先暂停再确认；
  主菜单加入原始素材徽章水印（assets/ui/title_logo.png）。
- 音效事件扩充完成：击毁爆炸、低血量警报、生产完成、增援到达、指令错误、
  胜利/失败旋律（dump 数字素材按时长推测映射，assets/se/*.ogg 可直接替换试听）。

二、最高优先级：明确问题
--------------------------
- 真实 LÖVE 窗口人工试听全部音效（尤其 7 个新事件），不对的改 config/audio.lua 的 file 字段。
- 真实窗口完整走一遍训练关九个步骤（自动化只验证到步骤二与无窗口链路）。

三、界面与菜单
--------------
- 右侧扩容，避免舰队管理、资源、通讯和必杀特写互相遮挡。
- 提高“资源”和“舰队管理”按钮的尺寸、对比度、悬停和禁用状态。
- 主菜单保留开始游戏/选关，并增加机体预览入口。
- 机体预览显示角色、机型、HP、EN、普通攻击和必杀技。
- 预览使用不会移动的高生命木偶，木偶持续回血；点击技能显示说明并自动循环演示。
- 预览必须是独立状态，不能污染正式战局、经济、单位列表或存档。
- 背景替换：ob12 系列是天空图与深空题材不符，testbg 仅 512px；
  可用 dump/slg/stage 的 256px 平铺星空块与穹顶着色器叠加重做每关底图。

四、招募、成长和经济
--------------------
- 区分关卡内临时招募和关卡外永久招募。
- 关卡内使用采集货币，随机招募成本低、数值约为永久版本的 0.5 倍。
- 关卡外使用关卡掉落宝石，可指定角色和机体，永久加入舰队。
- 增加四星/五星角色稀有度、重复角色转化为命座/成长材料和数值提升。
- 随机招募与指定招募使用不同价格、概率、角色池和数值模板。
- 制作独立招募演出：普通结果快速展示，五星结果增加特写、闪光和稀有度标识。
- 维修机、战机和特殊机体的生产应支持指定驾驶员，不再只有随机角色。

五、战斗、对白和内容
--------------------
- 每种机体保留独立 logic.lua 与 dialogue.lua；通用行为放共享模块。
- 扩展远程范围、远程定点、轰炸扫射、拦截突进、护盾、全图维修、工具维修等技能。
- 继续降低瞬间击杀：平衡 HP、伤害、攻击频率、弹道偏移、移动速度和地图规模。
- 跟随某角色时提高对应闲聊组合权重，但保留整体冷却，避免高频刷屏。
- 关卡剧情只写在关卡脚本；判定对白写角色文件；随机闲聊写角色/互动文件。
- 增加战前鼓励、中场支援、护送、失败反馈、战况评价和敌方挑衅。
- 敌方角色保留较少但更有针对性的攻击、挑衅、受击和败北台词。
- 训练关继续由可可、诺阿、雷斯特、阿尔茉分工教学。

六、素材、整理和发布
--------------------
- `dump` 是原始素材仓库，不能误删；运行代码应优先引用 `assets/`。
- 不要把原始素材直接混入 assets；实际运行素材必须使用可读文件名和显式映射。
- 为 Windows 准备 `build_release.bat`：检查 LÖVE 版本、复制项目、生成可发布目录，并预留 LOVE 单文件/EXE 合并步骤。
- 发布前验证 assets、字体、音效、存档目录和中文路径兼容性。
- assets/assets.tbl 是无代码引用的死清单（ou23 系列本就不存在），可择机删除。

七、未来伪 3D和第一人称
------------------------
- 保持 Game、Unit、Projectile、Skill 接口不变。
- 第一阶段设计二维平面第一人称接管：从单位面板进入，玩家控制一台机体，其余由 AI 控制，退出后恢复 RTT。
- 真正自由飞行 3D、模型、三维碰撞和渲染管线另立阶段，不在当前版本迁移引擎。
